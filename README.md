# Festa Geo

Convite digital elegante para aniversário de 15 anos, desenvolvido com **Next.js**, com foco em uma experiência bonita, responsiva e simples de manter.

O projeto possui:

- página inicial com foto de destaque
- mensagem principal
- detalhes do evento
- dress code
- galeria de fotos
- informações importantes
- confirmação de presença via PIN
- API interna para RSVP

---

## Tecnologias utilizadas

- **Next.js**
- **React**
- **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**
